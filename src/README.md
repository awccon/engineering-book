# The Modern Software Engineer

**From C#/.NET developer to full-stack, cloud and AI-capable software engineer.**

This book takes a developer with C#/.NET experience and builds them into a modern
professional engineer across the backend, databases, frontend, cloud, DevOps,
containers, Linux and AI application engineering — with smaller sections on Python
and Rust.

It teaches not only *how* to use each technology, but:

- **why** it works the way it does,
- **how it fits** into a larger system,
- **what problems** it solves and what costs it introduces,
- **what can go wrong**, and
- **how experienced developers think** about it — including when *not* to use it.

## A living book

This is not a frozen text. Technologies change, so the book separates
**durable knowledge** (concepts that stay true for years) from **current details**
(versions, APIs and services that change). Current details are reviewed regularly,
and every update is listed on the [What's Changed](front/changelog.md) page.
