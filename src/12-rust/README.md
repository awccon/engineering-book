## Read alongside this book

These chapters teach Rust by comparing it with C# and building two Beacon components. To see more of
the language, keep the official, free Rust references open while you read:

- [*Rust By Example*](https://doc.rust-lang.org/rust-by-example/index.html): short, runnable examples
  for each language feature, many of which you can edit and run in the browser. It's the quickest way
  to see how a feature looks in real code, and a good place to experiment after each chapter.
- [*The Rust Programming Language*](https://doc.rust-lang.org/book/) ("the Book"): the full official
  tutorial, with longer explanations of each feature.
- [Rustlings](https://github.com/rust-lang/rustlings): small exercises that check your understanding.
