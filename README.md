# The Modern Software Engineer

A living online book: from C#/.NET developer to full-stack, cloud and AI-capable software engineer.

- Source: Markdown in `src/`, one folder per book, one file per chapter.
- Built with [mdBook](https://rust-lang.github.io/mdBook/) and deployed to GitHub Pages on every push to `main`.
- Updates are proposed as pull requests and logged in `src/front/changelog.md`.

## Local preview

```bash
mdbook serve --open
```
